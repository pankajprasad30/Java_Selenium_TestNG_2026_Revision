Git important commands:
1. git --version : To check the version of git
2. git init : To initialize empty repository
3. git clone : To copy repo from server to local pc
4. git status : To check which file is newly added
5. git add . : To add all new file
5. git commit -m "Your Message" : To show the message in server
6. git push --all Paste repo link

.............................
7. git pull "Repo Link" : To pull updated new file from server to local.
8. git fetch : is used to check list of branches available.
9. git checkout "Branch name" : To send on particular branch.

.............................................
10. git branch branch_name : To create new branch in local
11. git branch : It will show list of available branch
12. git checkout branch_name: to switch the branch where you want to push the code.
